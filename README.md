# burmister.com

Adam Burmister's personal CV and portfolio website. Powered by Astro, Vite,
TypeScript, Three.js (WebGL), xterm.js, and Cloudflare.

![](public/assets/images/thumbnail.png)

## Development

```sh
npm run dev
```

## Build

```sh
npm run build
```
